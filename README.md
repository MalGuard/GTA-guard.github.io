# GTA Guard · Web presence

**GTA Guard** is the first product focus of the MalGuard defensive security project: helping people inspect potentially risky game modifications, plugins and related files.

This repository contains the GTA Guard web page. Find current product information, supported workflows and release availability on the official MalGuard website.

- [GTA Guard product information](https://malguard.github.io/gta-guard.html)
- [Current release status](https://malguard.github.io/download.html)
- [Documentation](https://malguard.github.io/docs.html)
- [MalGuard Core source](https://github.com/MalGuard/malguard-core)

## Inspect before you trust

A clean static scan cannot prove that a modification is harmless. Isolation depends on verified backend capabilities, and incomplete checks must be reported explicitly.

Created by **Mohammad Reza Azarderakhsh**, as part of [MalGuard](https://github.com/MalGuard).
